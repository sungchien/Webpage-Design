第三週：利⽤  HTML 建構網⾴內容架構
各位同學好，歡迎開始學習網⾴設計。今天我們的⽬標是正式認識  HTML ，這是⼀切網⾴的基礎  。
HTML 的全名是  Hyper Text Markup Language ( 超⽂本標記語⾔ )，它不像⼀般的程式語⾔，⽽是⼀種
⽤來「標⽰」內容的⼯具  。它的主要⼯作是定義網⾴的結構，告訴瀏覽器哪裡是標題、段落或圖⽚，讓
內容能正確呈現  。

第⼀節：基本  HTML ⽂件結構與元件概念
所有  HTML ⽂件都有⼀個共通的根基，由許多稱為「元件  (Element) 」的單位組成  。⼀個元件通常由
「開始標籤」和「結束標籤」組成，內容則夾在中間  。
 <!DOCTYPE html> ：這是在⽂件開頭的宣告，告訴瀏覽器這份⽂件是⽤最新的  HTML5 標準寫的  。
 <html> ：整個⽂件的根元素，像是⼀個最⼤的容器，把所有東西都包在裡⾯  。
 <head> ：這裡放的是給瀏覽器看的「幕後資訊」，如網⾴標題、編碼⽅式等，⾴⾯上通常看不到  。
 <body> ：這裡放的是所有使⽤者在網⾴上看得到的內容，如⽂字、圖⽚、連結等  。
範例：
<!DOCTYPE html>
<html>
<head>
    <title>我的第⼀個網⾴</title>
</head>
<body>
    這是⼤家在瀏覽器視窗中會看到的內容。
</body>
</html>
⽼師的真⼼話
新⼿最常犯的錯誤之⼀就是忘記寫結束標籤，或是結束標籤忘了加斜線   /  。當你發現⾴⾯排版怪
怪的時候，請先回來檢查標籤是否成對  。
特別提醒： 如果你忘記了  VS Code 的基本操作（例如：如何建⽴資料夾、新增   .html  檔案、存
檔或執⾏網⾴），請務必翻閱第⼆次的講義（製作第⼀個網⾴），裡⾯有詳盡的開發環境建⽴步驟
。
【⼩練習】：
請在桌⾯上新增資料夾 HTML_Practice ，開啟  VS Code 並在 HTML_Practice 資料夾中建⽴⼀個名為
 index.html  的檔案，試著打出上述的基礎結構，並在   <body>  中寫下⼀句你想對這⾨課說的話。

第⼆節：網⾴的幕後設定區  —  <head> 
 <head>  內的內容雖然不直接呈現在網⾴主體上，但對瀏覽器和搜尋引擎（ SEO ）來說極其重要  。
 <title> ：顯⽰在瀏覽器分⾴上的標題，對搜尋引擎優化⾮常重要  。
例⼦  1： <title>2025 個⼈網⾴製作 </title> 
例⼦  2： <title> 關於我  - 我的作品集 </title> 
 <meta charset="UTF-8"> ：務必指定使⽤  UTF-8 編碼，否則中⽂內容會變成亂碼  。
 <meta name="viewport" ...> ：讓網⾴在⼿機、平板上能以正確⽐例顯⽰，這在⾏動優先的時代⾮
常重要  。
 <link> ：最推薦的外部樣式表引⼊⽅式，⽤來連接  CSS 檔案  。
例⼦  1： <link rel="stylesheet" href="style.css"> 
 <style> ：適合為「單⼀⾴⾯」快速加上簡易樣式，但不建議在⼤型專案中使⽤  。
例⼦  1： <style> body { background-color: #f0f0f0; [cite_start]} </style> 
【⼩練習】：
請修改你剛才建⽴的   index.html ，將   <title>  設定為「 ( 你的名字 ) 的個⼈⾸⾴」，並確認是否有加上
 charset="UTF-8" 。

第三節：標題與⽂字
⽂字是傳達訊息的核⼼， HTML 透過不同標籤來賦予⽂字意義與結構  。
** <h1>  到   <h6>** ：標題標籤， <h1>  字體最⼤且最重要，⽤於主標題； <h6>  則最⼩  。
例⼦  1： <h1> 本週網⾴設計重點 </h1> 
例⼦  2： <h2> 第⼆節：標題的使⽤規範 </h2> 
 <p> ：段落標籤，⽤於⼀般的⽂字內容  。
例⼦  1： <p> 這是⼀個說明  HTML 基礎的段落。 </p> 
例⼦  2： <p> 透過練習，我們能更熟悉標籤的⽤法。 </p> 
⽼師的真⼼話
請不要為了讓⽂字變⼤或變粗⽽濫⽤標題標籤  。標題層級代表⽂章的結構⼤綱，這對搜尋引擎和
視障⼈⼠使⽤的螢幕閱讀器⾮常重要  。
【⼩練習】：
請先刪除  HTML 中⽬前的⽂字，然後加⼊⼀個   <h1>  寫上「我的興趣」，並在下⽅⽤兩個   <p>  標籤描述
你最喜歡的⼀項活動。

第四節：語意化區塊
HTML5 推出了更有「語意」的區塊標籤，取代過去⼤量使⽤的   <div> ，讓程式碼結構更清晰  。
 <header> ：⾴⾸，通常放置  Logo 、網站名稱或主選單  。
 <nav> ：導覽列，專⾨⽤來放置主要連結的地⽅  。
 <section> ：⽂件中的⼀個獨⽴區塊，例如⼀個章節或⼀篇⽂章  。
 <footer> ：⾴尾，通常放置版權資訊、聯絡⽅式等  。
範例：
<header>
    <h1>⼩明的⼯作室</h1>
    <nav>
        <a href="index.html">⾸⾴</a> | <a href="contact.html">聯絡我</a>
    </nav>
</header>
<section>
    <h2>最新作品</h2>
    <p>這裡展⽰了我最近完成的網⾴專案。</p>
</section>
【⼩練習】：
嘗試⽤上述標籤規劃網⾴：將原有的標題放⼊   <header> ，並在⾴⾯最下⽅加⼊⼀個   <footer>  寫上「 ©
2025 ( 你的姓名 ) 」。

第五節：超連結
超連結是網路的靈魂，它讓我們可以在不同的⾴⾯之間⾃由跳轉  。
 <a>  (Anchor)：錨點標籤，使⽤   href  屬性來指定⽬標網址  。
例⼦  1 （連⾄外部）： <a href="https://www.google.com"> 前往  Google</a> 
例⼦  2 （連⾄內部）： <a href="about.html"> 關於我們 </a> 
【⼩練習】：
在你的網⾴中新增⼀個連結，讓點擊後可以連到你系上的官網或你常去的⼊⼝網站。

第六節：圖⽚
圖⽚能豐富網⾴的視覺體驗，使⽤時需注意路徑與替代⽂字  。
 <img> ：圖⽚標籤，它沒有結束標籤  。
 src  屬性：指定圖⽚的路徑  。
 alt  屬性：當圖⽚無法顯⽰時出現的替代⽂字  。
例⼦  1： <img src="images/logo.png" alt=" 網站標誌 "> 
例⼦  2： <img src="cat.jpg" alt=" ⼀隻坐在窗邊的虎斑貓 "> 
⽼師的真⼼話
 alt  屬性⾮常重要，請務必養成撰寫習慣  。它不僅能幫助看不到圖⽚的使⽤者了解內容，也能在
路徑錯誤時提供線索，對  SEO 也有加分效果  。
【⼩練習】：
在專案資料夾放⼊⼀張⼩圖，並在網⾴中正確顯⽰它，同時為它寫下精確的   alt  描述。

第七節：列表
當需要條列多個項⽬時，列表標籤能讓內容層次分明  。
 <ul>  (Unordered List)：無序列表，會以項⽬符號（圓點）呈現  。
 <ol>  (Ordered List)：有序列表，會以數字  (1, 2, 3) 呈現  。
 <li>  (List Item)：列表中的每⼀個項⽬  。
例⼦  1： <ul> <li> ⽜奶 </li> <li> 雞蛋 </li> </ul> 
例⼦  2： <ol> <li> 步驟⼀ </li> <li> 步驟⼆ </li> </ol> 
【⼩練習】：
使⽤   <ul>  標籤列出三件你今天想要完成的事情。

第⼋節：表格
表格是⽤來呈現具備結構性資料（數據、課表等）的最佳⽅式。
 <table> ：定義整個表格。
 <tr>  (Table Row)：代表表格中的每⼀列。
 <th>  (Table Header)：表頭儲存格，內容預設會加粗置中。
 <td>  (Table Data)：⼀般的資料儲存格。
範例：
<table>
  <tr>
    <th>姓名</th>
    <th>分數</th>
  </tr>
  <tr>
    <td>王⼩明</td>
    <td>95</td>
  </tr>
</table>
【⼩練習】：
試著建⽴⼀個簡易課表，包含兩列：第⼀列是表頭（科⽬、時間），第⼆列填⼊你現在這堂課的資訊。

第九節：萬⽤容器  —  <div> 
當找不到更符合語意的標籤，但⼜需要將內容分組以便設定  CSS 時， <div>  是你的最後防線  。
 <div>  (Division)：沒有特殊語意的通⽤型容器  。
例⼦  1：⽤來將產品圖⽚與價格包在⼀起。
例⼦  2：
<div class="product-card">
    <h2>⾼級咖啡⾖</h2>
    <p>價格： $500</p>
</div>
【⼩練習】：
嘗試⽤⼀個   <div>  將你剛才練習中的⼀個標題與⼀個段落包起來。
寫網⾴就像堆積⽊，先學會每⼀塊積⽊的⽤途，很快你就能組合出屬於⾃⼰的精彩作品了  ！
