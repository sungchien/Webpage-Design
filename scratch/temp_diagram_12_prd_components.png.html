1. 網站目標 Goal
為誰解決什麼問題
說明官網設立目的，例如讓客人線上看菜單、了解自烘豆理念與來店路線 (CTA)。
2. 目標受眾 Audience
網站是做給誰看的
界定核心讀者（如：用筆電的上班族、大學生）與次要讀者（社區鄰居）。
3. 視覺調性 Vibe
Vibe Coding 的靈魂
日系侘寂風、黑金專業商務風、暗黑霓虹；定義色彩 HEX 代碼與字體風格。
4. 功能區塊 Features
單頁式由上至下佈局
Navbar 導覽列 ➔ Hero 主視覺 ➔ About Us ➔ Menu 菜單 ➔ Contact & Map ➔ Footer。
5. 技術要求 Tech Specs
前端工程規範
單頁式 (SPA)、Tailwind CSS CDN、Mobile-First 響應式 (RWD)、HTML5 語意標籤。
