PRD (產品需求文件) 五大核心要素與技術護欄
指揮 AI 代理人精準實作多頁式原生網站的唯一真相來源 (Single Source of Truth)
1. 網站目標 Goal
為誰解決什麼問題
說明官網設立核心目的，例如傳遞專業信賴感、展示服務項目並引導線上預約初談 (CTA)。
2. 目標受眾 Audience
網站是做給誰看的
界定主要受眾（如：高壓上班族、青年）與次要受眾（家長、社區居民）的瀏覽情境。
3. 視覺風格 Vibe
色彩計畫與氛圍調性
拒絕模糊形容詞！明確指定至少 3 組 HEX 色票代碼（背景、主色、點綴色）與襯線/黑體搭配。
4. 網站地圖 Site Map
4 頁獨立架構與導航
明確定義 index.html 等 4 個分頁檔名、各頁區塊階層，以及全站共用導覽列 active 規範。
5. 技術護欄 Tech Guardrails
限定原生三劍客・禁框架
限定 HTML5 語意標籤 ＋ 外部 style.css ＋ 原生 script.js；嚴禁 Vue / React 等需編譯框架。
同儕審查 & Planning
消除盲點再動工
經同儕排雷並啟動 Planning Mode 檢視檔案樹後，才算真正合格的 AI 施工藍圖！
