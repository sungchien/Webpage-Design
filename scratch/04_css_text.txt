第⼀節：如何將  CSS 加⼊  HTML ？
在開始化妝前，我們得先決定「化妝品」要放在哪裡。通常有三種常⾒的做法：
1. 外部樣式表  (External CSS)
這是最推薦的⽅式。我們會將所有的樣式寫在⼀個獨⽴的   .css  檔案中，並在  HTML 的   <head> 
區塊內引⼊。
HTML 檔案  ( index.html ) ：

  <link rel="stylesheet" href="mystyle.css">
</head>

  background-color: lightblue;
}

直接將  CSS 寫在  HTML 檔案的   <style>  標籤內。這適合⽤於「只有該⾴⾯需要特殊樣式」的場
合。

第⼆節： CSS 的基本語法結構
CSS 的語法就像在下指令：「嘿，幫我把某個東西，變成某些樣⼦。」
1. 語法構成
⼀段完整的  CSS 規則包含兩個主要部分：
1. 選擇器  (Selector)：放在⼤括號的前⾯，告訴瀏覽器你要改變哪個  HTML 元素。
2. 宣告區塊  (Declaration Block)：即⼤括號   { }  內的部分。
2. 多重宣告
在⼀個宣告區塊中，可以包含多對「屬性與值」。每⼀對屬性與值之間⽤冒號   :  分隔，且每⼀對
的結尾都必須加上分號   ; 。
範例解析：
/* 選擇器  */  /* 宣告區塊開始  */
h1 {
  color: blue;          /* 屬性 1: 值 1; */
  font-size: 24px;      /* 屬性 2: 值 2; */
  text-align: center;   /* 屬性 3: 值 3; */
}                       /* 宣告區塊結束  */
⽼師的真⼼話：
初學者最常犯的錯就是 ** 漏掉分號   ;** 。如果漏寫了，瀏覽器會看不懂下⼀⾏指令，導
致整段樣式失效。
雖然  CSS 不強制縮排，但像範例那樣把每個屬性換⾏寫，會讓程式碼清楚很多，這也是
專業⼯程師的⾃我要求。

第三節：精準選取⽬標：常⽤選擇器
為了讓網⾴不同部分有不同的美感，我們需要運⽤多種「選擇器」來精確定位。
1. 元素選擇器  (Element Selector)
直接使⽤  HTML 的標籤名稱。這會影響⾴⾯上「所有」該標籤的元素。
範例：  p { color: gray; } （這會讓所有段落⽂字都變成灰⾊）。
2. ID 選擇器  (ID Selector)
每個  HTML 元素都可以有⼀個獨⼀無⼆的  ID 。在  CSS 中，我們使⽤   #  符號來選取它。
HTML ：  <div id="header-section">...</div> 
CSS ：
#header-section {
  background-color: gold;
}
3. Class 選擇器  (Class Selector)
Class ( 類別 ) 則像⾐服的標籤，可以重複套⽤在不同的元素上。在  CSS 中，我們使⽤   .  ( 點 ) 符號
來選取它。
HTML ：  <p class="important-text"> 注意！ </p> 
CSS ：
.important-text {
  font-weight: bold;
  color: red;
}

4. 群組選擇器  (Grouping Selector)
如果你想讓多個不同的元素擁有相同的樣式，可以⽤ ** 逗號   ,**  將它們串在⼀起，減少重複寫程
式碼。
範例：
h1, h2, p {
  font-family: Arial;
} /* 讓  h1, h2 和  p 通通使⽤  Arial 字型  */
5. 後代選擇器  (Descendant Combinator)
當你想選取「某個元素內部的特定元素」時使⽤。選擇器之間⽤空格隔開。
範例：選取導覽列裡⾯的連結
nav a {
  text-decoration: none;
} /* 只有在  <nav> 標籤裡⾯的  <a> 才會被去掉底線  */
⽼師的真⼼話：
ID 就像⾝分證號碼，⼀個⾴⾯中同⼀個  ID 只能出現⼀次；⽽  Class 就像制服，很多⼈
可以同時穿。
在實務上，我們最常使⽤  Class 來寫樣式，因為它的重⽤性最⾼。 ID 通常留給
JavaScript 抓取元素或是特定的⼤區塊定位使⽤。

1. 顏⾊與⽂字樣式  (Color & Text)
⽂字是網⾴的靈魂，透過  CSS 我們可以輕鬆控制⽂字的顏⾊、⼤⼩與對⿑。

第五節： CSS 盒模型  (Box Model)
在  CSS 的世界裡，請記住⼀個核⼼觀念：網⾴上的每⼀個元素，本質上都是⼀個「矩形盒⼦」。
不論是⼀個標題、⼀張圖⽚還是⼀個段落，瀏覽器都會將它們看作⼀個個盒⼦。這個盒⼦的結構由
內⽽外分為四層，我們稱之為  「盒模型」。
1. 盒⼦的四層結構
1. 內容  (Content)：
盒⼦裡真正裝的東西，例如⽂字或圖⽚。你可以透過   width  和   height  來設定這個區域的⼤
⼩。
2. 內距  (Padding)：
內容與邊框之間的距離。就像快遞箱⼦裡⽤來保護商品的泡棉。增加  Padding 會讓背景顏⾊
的範圍變⼤。
3. 邊框  (Border)：
包圍在內距和內容外的殼，就是箱⼦本⾝的厚度。
4. 外距  (Margin)：
盒⼦與其他盒⼦之間的距離。這就像是在箱⼦外⾯留的空位，⽤來確保箱⼦之間不會擠在⼀
起。
2. 誰決定了盒⼦的⼤⼩？  box-sizing
這是排版中最容易出錯的地⽅：當你設定   width: 300px  時，你設定的到底是「內容」的寬度，還
是「整個箱⼦」的寬度？

A. 標準模式： content-box  ( 瀏覽器預設值 )
在這種模式下，你設定的   width  只包含內容本⾝。如果你加了內距或邊框，盒⼦會被往外「撐
⼤」。
範例計算：
.standard-box {
  box-sizing: content-box;
  width: 300px;
  padding: 20px;          /* 左右共  40px */
  border: 5px solid blue; /* 左右共  10px */
}
結果：這個盒⼦在畫⾯上看到的總寬度會變成  350px ( ) 。這常導致排好的版
⾯因為多出的幾像素⽽跑掉。
B. 邊框模式： border-box  ( ⽼師強烈推薦 )
在這種模式下，你設定的   width  就是整個盒⼦的最終寬度。內距和邊框會「向內擠壓」，⽽不會撐
⼤盒⼦。
範例計算：
.modern-box {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 5px solid blue;
}
結果：總寬度就是準確的  300px。內容區域會⾃動縮⼩來容納內距與邊框，數學變得簡單多
了！

⽔平置中：
只要設定了寬度，並將左右外距設為   auto ，盒⼦就會在⾴⾯中央。

第六節：運⽤  CSS 的進階網⾴排版  - Flexbox
學會了盒模型，我們能精準控制單⼀元素的⼤⼩。但如果你想讓⼀群元素整⿑地排列（例如：讓三
個盒⼦⽔平並排、或是讓⽂字在圓圈正中央），過去是⾮常困難的。
現在，我們有了  Flexbox ( 彈性盒模型 )。它的核⼼概念是「容器  (Container)」和「項⽬
(Items)」。你只要在⽗層容器下指令，裡⾯的所有⼦層項⽬就會乖乖聽話。
1. 啟動  Flexbox
要開啟這個魔法，你只需要在「⽗元素」的  CSS 中加上⼀⾏：
.container {
  display: flex; /* 啟動彈性佈局  */
}
⼀旦啟動，⼦元素預設會像⽕⾞⾞廂⼀樣，從左到右⽔平排列。
2. 決定排列⽅向： flex-direction
你可以決定「⾞廂」要橫著放還是直著放：
 row ：⽔平排列（預設值）。
 column ：垂直排列（像⼤樓⼀樣上下堆疊）。
3. 主軸對⿑： justify-content
這是  Flexbox 最強⼤的地⽅，它能決定項⽬在「主要⽅向」上如何分配空間。
範例：讓選單項⽬平均分配
.nav-bar {
  display: flex;
  justify-content: space-between; /* 左右貼⿑，中間均分剩餘空間  */
}

 center ：全部擠在中間。

4. 交錯軸對⿑： align-items

範例：讓不同⾼度的⽂字在列中垂直置中

}

不要背，要試： Flexbox 的屬性很多，不需要死背。我建議⼤家在練習時，打開  Chrome
的「開發⼈員⼯具」，點擊   flex  標籤旁的圖⽰，可以直接勾選各種對⿑⽅式，即時看到
效果，這才是學習排版最快的⽅法！
