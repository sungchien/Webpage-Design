GitHub Pages 部署操作 3 步驟
將本機專案上傳至雲端，免費取得個人專屬公開網址
步驟 1
Commit & Publish
• GitHub Desktop 點擊 Commit to main
• 點擊 Publish repository
• !! 重要 !! 取消勾選 Keep this code private
➔
步驟 2
開啟 Pages 功能
• 前往 GitHub 倉庫 Settings > Pages
• Source 選擇 Deploy from a branch
• Branch 選擇 main，資料夾選 /(root) 儲存
➔
步驟 3
取得專屬網址
等待 1~3 分鐘即時發布完成！
網址格式：
https://帳號.github.io/專案名稱/
