 第⼀堂實作課：從零到⼀，打造你的第⼀個網⾴  
 各位同學好！理論說了這麼多，終究要動⼿做⼀次才會有感覺。今天這堂課，我們要⼀步步地、  
 從無到有，親⼿打造出⼀個簡單但完整的網⾴。  
 請跟著下⾯的步驟，我們開始吧！  
 第⼀節：課前準備－建⽴你的開發環境  
 在開始寫程式碼之前，我們需要先準備好⼯作的空間，就像畫家準備畫布和畫筆⼀樣。  
 1.  開啟你的編輯器   ：⾸先，請打開  Visual Studio Code (VS Code) 。  
 2.  建⽴專案資料夾   ：在你的電腦桌⾯上，新增⼀個資料夾，並將它命名為  myFirstPage 。  
 3.  在  VS Code 中開啟資料夾   ：回到  VS Code ，從頂端選單選擇「檔案」 > 「開啟資料夾」，然  
 後選擇我們剛剛建⽴的  myFirstPage 資料夾。  
 ⽼師的真⼼話：   每次開始⼀個新專案，都為它建⽴⼀個專屬的資料夾，是⼀個⾮常  
 重要的好習慣。這能讓你的檔案管理得井井有條，未來專案變⼤變複雜時，你絕對會  
 感謝現在的⾃⼰。

 第⼆節：撰寫  HTML ⾻架  
 我們的「畫布」準備好了，現在要來畫上網⾴的⾻架。  
 1.  建⽴  HTML 檔案   ：在  VS Code 左側的檔案總管區，點擊新增檔案的圖⽰，將檔案命名為  
 myFirstPage.html 。  
 2.  輸⼊  HTML 程式碼   ：在新建⽴的檔案中，輸⼊以下所有的  HTML 程式碼。  
 <!DOCTYPE html> 
 <html> 
 <head> 
 <title> 我的第⼀個網⾴ </title> 
 </head> 
 <body> 
 <main> 
 <h1> 網⾴ </h1> 
 <p> 網⾴是全球資訊網上，可以⽤瀏覽器存取的檔案。 </p> 
 <section> 
 <h2> 網址 </h2> 
 <p> 每⼀個放在網路上的網⾴都有⼀個網址，正式的名稱叫做 <strong> 統⼀資源定位器  
 (Uniform Resource Locator ， URL)</strong> 。 </p> 
 <p> 只需在瀏覽器上輸⼊網⾴的 URL ，便可以顯⽰這個網⾴。 </p> 
 </section> 
 <section> 
 <h2> 元素 </h2> 
 <p> 網⾴由多個元素構成，例如 :</p> 
 <ul> 
 <li> 標題元素 </li> 
 <li> 段落元素 </li> 
 <li> 圖像元素 </li> 
 </ul> 
 </section> 
 </main> 
 </body> 
 </html> 
 3.  儲存與執⾏   ：  
 ○  按下  Ctrl + S (Windows) 或  Cmd + S (Mac) 儲存檔案。  
 ○  在  VS Code 頂端選單選擇「執⾏」 > 「執⾏ ( 不偵錯 ) 」。  
 ○  此時，應該會⾃動打開⼀個新的瀏覽器視窗，顯⽰你剛剛完成的作品。  
 ⽼師的真⼼話：   在  VS Code 裡，你會看到程式碼有不同的顏⾊，這可以幫助我們區  
 分「元素標籤」和「內容」。這是程式碼編輯器貼⼼的地⽅，能讓程式碼更容易閱  
 讀。

 第三節：動⼿修改與觀察  
 網⾴的內容是可以隨時擴充的。現在，我們來試著新增⼀個區塊。  
 1.  加⼊新的  section  ：在第⼆個  <section> 結束標籤之後，加⼊以下這段關於「網⾴外觀」的  
 程式碼。  
 <section> 
 <h2> 網⾴的外觀 </h2> 
 <p> 設計網⾴外觀需要利⽤串接式樣式表 (Cascade Style Sheet ， CSS)</p> 
 <p> 這些外觀樣式，例如： </p> 
 <ul> 
 <li> 元素的寬與⾼ </li> 
 <li> 元素的背景顏⾊ </li> 
 <li> 元素的⽂字顏⾊ </li> 
 </ul> 
 </section> 
 2.  再次儲存與執⾏   ：重複上個步驟的儲存與執⾏動作。看看你的網⾴是不是出現了新的內容？  
 ⽼師的真⼼話：   當程式碼越來越⻑的時候，你會發現⾏數編號的左邊有⼀些⼩⼩的  
 ▼  符號。這就是「摺疊 / 展開」功能！你可以點擊它來暫時收合⼀個區塊的程式碼，  
 讓畫⾯更簡潔，幫助你專注在⽬前要修改的區塊上。這在處理複雜的檔案時⾮常好  
 ⽤！

 第四節：⽤  CSS 為網⾴化妝  
 我們的網⾴現在只有⾻架，看起來有點樸素。接下來，我們要⽤  CSS 來為它上妝，讓它變得更好  
 看。  
 1.  連結  CSS 檔案：⾸先，我們需要告訴  HTML 檔案要去哪裡找它的「化妝師」 (CSS 檔案 ) 。  
 請回到  myFirstPage.html ，在  <head> 區塊中， <title> 元素的下⼀⾏，加上這段程式碼：  
 <link rel="stylesheet" href="myFirstPage.css"> 
 2.  建⽴  CSS 檔案   ：接著，我們來建⽴化妝師本⼈。和前⾯⼀樣，在  VS Code 左側新增⼀個檔  
 案，並命名為  myFirstPage.css 。  
 3.  撰寫  CSS 樣式規則   ：在  myFirstPage.css 檔案中，輸⼊以下的樣式規則。  
 main { 
 width: 80%; 
 margin: auto; 
 background-color: rgb(255, 239, 213); 
 padding: 20px; 
 } 
 h1 { 
 text-align: center; 
 color: rgb(25, 25, 112); 
 } 
 section { 
 margin-top: 20px; 
 padding: 10px; 
 border-top: 2px solid rgb(25, 25, 112); 
 } 
 4.  最後的儲存與執⾏   ：  
 ○  儲存  myFirstPage.css 檔案。  
 ○  回到  myFirstPage.html 檔案，再執⾏⼀次。  
 ○  看看你的網⾴，是不是瞬間變得不⼀樣了呢？  
 ⽼師的真⼼話：   這次我們⽤的⽅法叫做「外部樣式表」，是把  CSS 寫在⼀個獨⽴的  
 檔案裡，這是最推薦、也最⽅便管理的⽅式。其實，要為網⾴加上樣式還有另外兩種  
 ⽅法：「內部樣式表」（在  HTML 檔案內⽤  <style> 標籤）和「⾏內樣式表」（直接  
 寫在  HTML 標籤上）。這三種⽅法的細節和使⽤時機，我們會在之後專⾨講授  CSS 
 的課程中詳細說明。

 [ 補充 ] VS Code 編輯⼩技巧  
 除了程式碼摺疊， VS Code 還有很多好⽤的功能可以加速你的開發：  
 ●  多重游標編輯   ：按住  Alt ( 在  Mac 上是  Option) ，然後⽤滑⿏在不同⾏點擊，可以建⽴多個   游  
 標。這樣你就可以同時在好幾個地⽅輸⼊或修改相同的⽂字，超級⽅便！  
 ●  ⾃動完成  (IntelliSense)  ：當你開始輸⼊⼀個  HTML 標籤或  CSS 屬性時， VS Code  會⾃動跳  
 出建議選項，按下  Enter 或  Tab 就可以快速完成輸⼊，減少拼錯字的機會。  
 ●  快速註解   ：選取⼀段程式碼，然後按下  Ctrl + / ( 在  Mac 上是  Cmd + /) ，可以快速   地將這段  
 程式碼變成註解（暫時讓它失效），再按⼀次就可以取消註解。  
 ●  格式化⽂件   ：如果你的程式碼縮排變得很亂，可以按  Shift + Alt + F ( 在  Mac 上是   Shift + 
 Option + F) ， VS Code 會⾃動幫你把整個檔案的排版整理好。  
 學會使⽤這些⼩⼯具，能讓寫程式的過程更順暢愉快喔！
